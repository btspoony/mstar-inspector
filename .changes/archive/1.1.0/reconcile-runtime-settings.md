- **Recovery reconcilers:** Platform operators can configure lifecycle and Check recovery request budgets, timeouts, batch sizes and attempt caps in Admin → Runtime. Each run uses one snapshot; invalid or unavailable settings fall back to the unchanged defaults with redacted diagnostics.

- **恢复协调器：** 平台操作员可在 Admin → Runtime 配置生命周期与 Check 恢复的请求预算、超时、批量大小和尝试次数上限。每轮使用一次快照；设置无效或无法读取时，保留原有默认行为并记录脱敏诊断。
