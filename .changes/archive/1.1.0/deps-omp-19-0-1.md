- **omp SDK 19.0.1 across root and runner**: the root and `packages/runner` manifests both move `@oh-my-pi/pi-coding-agent` from `18.22.2` to `19.0.1`, and both lockfiles re-resolve so the entire `@oh-my-pi/*` family stays on a single 19.0.1 copy. The harness engine, CLI and image ref stay on 4.8.0. 19.0.0's SDK breaking changes (`createAgentSession.cacheWarming` is now `"off" | "streaming" | "idle"` instead of a boolean, `session.handoff` is replaced by `session.compact(..., { mode: "handoff" })`, `artifact://` links become `local://`, and `deferSkillDescriptionCompression` / `startSkillDescriptionCompression()` are renamed) are not used by this repo's session options or review runner, so no runtime contract change is included. The vendored provider-catalog snapshots are re-extracted from the installed `@oh-my-pi/pi-catalog` 19.0.1; the provider and model vocabulary is unchanged, only the recorded source version and extraction date move. The `# image-inputs:` fingerprint is refreshed in the same commit because `packages/runner/package.json` and its lockfile are image inputs.

- **omp SDK 升至 19.0.1（根与 runner）**：根目录与 `packages/runner` 的 `@oh-my-pi/pi-coding-agent` pin 均从 `18.22.2` 升到 `19.0.1`，两个 lock 重新解析，整组 `@oh-my-pi/*` 保持单一的 19.0.1 副本。harness engine、CLI 与镜像 ref 仍停留在 4.8.0。19.0.0 的 SDK 破坏性变更（`createAgentSession.cacheWarming` 由布尔值改为 `"off" | "streaming" | "idle"`、`session.handoff` 改为 `session.compact(..., { mode: "handoff" })`、`artifact://` 改为 `local://`，以及 `deferSkillDescriptionCompression` / `startSkillDescriptionCompression()` 更名）未被本仓库的 session 选项或 review runner 使用，因此没有运行时契约改动。从已安装的 `@oh-my-pi/pi-catalog` 19.0.1 重新提取了 vendored provider-catalog 快照；提供方与模型词汇未变，仅记录的源版本与提取日期更新。同一提交中刷新了 `# image-inputs:` 指纹，因为 `packages/runner/package.json` 及其 lock 是镜像输入。
