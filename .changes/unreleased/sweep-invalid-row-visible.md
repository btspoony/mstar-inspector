- The Runtime page's Scheduled failure sweep card no longer blanks every input when one stored sweep setting is invalid: valid stored values stay filled, only the invalid field is cleared and marked, and the notice names that field and asks the operator to enter a valid value and save instead of offering a Retry that cannot repair a bad row. A failed settings read still blanks all fields and keeps Retry.

<!-- CN -->
- Runtime 页的「定时失败巡检」卡片在某一项已存巡检设置无效时不再清空全部输入：有效的已存值保持显示，只清空并标出无效字段，提示文案点名该字段并要求填写有效值后保存，而不是提供无法修复坏数据行的「重试」。设置读取整体失败时仍清空全部字段并保留「重试」。
