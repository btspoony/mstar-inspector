- **Harness 4.8.0 across root, runner and the review image**: the root manifest's `@mstar-harness/engine` range moves to `^4.8.0`, `packages/runner`'s exact pin to `4.8.0`, and the image's `@mstar-harness/cli` global install, `HARNESS_VERSION` / `harnessRef` pin (ref `74fc9ae4457f78bd8f170705edb48a58fceacdd8`, tag `v4.8.0`) and Dockerfile clone ref move with them; every lockfile regenerates and the image-inputs fingerprint is refreshed in the same commit because those manifests, lockfiles and the pinned ref are image inputs. 4.8.0 fixes the harness root to `<git main worktree root>/.mstar` (retiring `.mstarc` `harness_dir`, `MSTAR_HARNESS_DIR`, and the legacy `.agents/` / `.plans/` / `plans/` candidates as selectors), stops MCP from pinning a connection root, points linked-worktree scaffold and PM/persist/dashboard selectors at the main worktree, and adds Devin native plugin support, the on-demand `mstar-issue-mirror` skill, an owner-feedback disposition, PR CI/review routing back to the owning implementer, direct invocation for `code-reviewer` / `ops-engineer`, and a Codex `code-reviewer` agent, plus the monorepo version alignment. Those land on the harness's own surfaces; this repo's declared corpus layout and the review/seat contract it consumes are unchanged by the pin.

- **harness 升至 4.8.0（根、runner 与审查镜像）**：根 manifest 的 `@mstar-harness/engine` 区间改为 `^4.8.0`，`packages/runner` 的精确 pin 改为 `4.8.0`，镜像全局安装的 `@mstar-harness/cli`、`HARNESS_VERSION` / `harnessRef` pin（ref `74fc9ae4457f78bd8f170705edb48a58fceacdd8`，tag `v4.8.0`）与 Dockerfile 克隆 ref 一并向 4.8.0 移动；所有 lock 重新生成，并在同一提交中刷新 image-inputs 指纹——这些 manifest、lock 与所 pin 的 ref 都是镜像输入。4.8.0 将 harness 根固定为 `<git 主 worktree 根>/.mstar`（`.mstarc` 的 `harness_dir`、`MSTAR_HARNESS_DIR` 以及旧的 `.agents/` / `.plans/` / `plans/` 候选不再作为选择器），MCP 不再钉死连接根，linked worktree 的 scaffold 与 PM/persist/dashboard 选择器都指向主 worktree，并新增 Devin 原生插件支持、按需 `mstar-issue-mirror` skill、owner-feedback disposition、将 PR CI/审查结果路由回所属 implementer、`code-reviewer` / `ops-engineer` 的直接调用，以及 Codex `code-reviewer` agent，同时完成 monorepo 版本对齐。这些都落在 harness 自身表面上；本仓库已声明的语料布局，以及所消费的 review/seat 契约，不因这次 pin 升级而改变。
